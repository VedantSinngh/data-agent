# DataTrust Agent

An evidence-grounded AI agent that detects data-quality issues, explains their business impact, and proposes validated, human-approved corrections.

## Overview
DataTrust Agent analyzes CSV and Excel datasets, identifies data-quality issues using Python, explains those issues using an LLM grounded in data dictionaries and quality rules, and proposes safe corrections with measurable before-and-after results.
